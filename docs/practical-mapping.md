# Mapping the project to SI Practical 1–8

The exact wording can differ between lab sheets; this mapping follows the uploaded practical PDFs.

| Practical | Topic visible in uploaded material | Where it appears in this project |
|---|---|---|
| 1 | Requests, HTTP response, HTML parsing, extracting web data | Backend scraper: Books to Scrape using Requests and BeautifulSoup |
| 2 | Web scraping structured country data; Pandas cleaning, descriptive statistics and plots | Scraping workflow, dataset preview, summary statistics and correlation panels |
| 3 | Probability, population/sample and uniform, normal, binomial and Poisson distributions | Statistics panel includes a sampling/CLT demonstration; distribution concepts can be discussed in the viva |
| 4 | Central Limit Theorem, repeated samples, sampling distribution, point estimate and standard error | CLT panel generates repeated sample means and reports their mean and standard error |
| 5 | Pandas dataset exploration, summary statistics, hypothesis tests / before-after comparisons | Overview panel reports shape, missing values, descriptive statistics; use listing features for exploratory analysis |
| 6 | Two-sample t-test, paired t-test, ANOVA, chi-square, covariance/correlation and significance tests | Correlation panel reports Pearson/Spearman and p-values; correlation matrix is included |
| 7 | Regression, train-test split, normalization/standardization, label encoding and model evaluation | Model training uses train/test split, one-hot encoding, imputation and five regression models |
| 8 | Medical-insurance cost regression with Linear/Ridge/Lasso/Decision Tree/Random Forest and MAE/MSE/R² | Same regression model comparison pattern adapted to nightly Airbnb price prediction |

## Presentation note

The application integrates the topics into one use case rather than reproducing every practical as a separate notebook. For a lab evaluation, explain the purpose of each module and show its API response or UI output. The synthetic bundled dataset is clearly labelled; use a permitted public listings CSV for research-quality analysis.
